How it works

Monad Foundation announcements, with their signatures checked on-chain.

The problem

The Monad Foundation publishes node-ops announcements in mf-nodeops-comms, each signed with GPG. An announcement counts only if two of the Foundation's keys signed it. Checking that by hand means installing gpg, importing the keys, comparing their fingerprints and verifying every signature, for every announcement.

What this does

The check runs once, on Monad, and everyone reads the result.

  1. The Foundation signs. It publishes announcement.txt and announcement.sig on GitHub, as it already does.
  2. Anyone proves each signature. A zero-knowledge proof shows "this exact text was signed by this Foundation key". Producing it repeats what gpg does: read the signature packet, hash the text (SHA-256 or SHA-512) and verify the Ed25519 signature. It takes about 20 seconds, on the submit page or the command line.
  3. The registry verifies. A contract on Monad checks each proof against the text and the Foundation's keys, which were fixed when it was deployed. A wrong text, key or proof is rejected, as is an expired signature.
  4. Two keys make it official. When two different Foundation keys have signed the same text, the registry stores it. The announcements page reads it back from the chain.

The signatures themselves never go on-chain: the proofs stand for them.

Who you trust

You trust the Foundation's keys, the open-source code of the circuit and the contract (not audited), and the RPC or node you read from.

You don't trust whoever proves or submits an announcement, GitHub, or where the files came from. Nobody can register a text the Foundation didn't sign: there would be no valid proof for it.

A page can show anything, so read from your own copy: deploy it from the repository, and point Settings at your own node.

Check it yourself

With Foundry, against your own node, where REGISTRY is the address under Settings on the announcements page:

cast call $REGISTRY "keySet()(bytes20[])"
cast call $REGISTRY "announcement(uint64)(string,bytes20[])" 6

The first must list the fingerprints in gpg-keys.json. The second prints the text of announcement #6 and the two keys that signed it.

If the Foundation changes its keys, a new registry is deployed with the new ones, and this page moves to it.
